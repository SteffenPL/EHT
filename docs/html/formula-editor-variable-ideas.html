Formula editor and documentation concept

Make formula variables visible, local, and visual

Grounded in current repo state Inspected formula editor, EHT parameter UI, external-force evaluation, parameter descriptions, and user-facing docs.

What already exists

Rich formula dialog

2

Named helpers

Constants

A constants tab lets users define shared names such as heartbeat, then reuse them in formulas.

4

External variables exist

The dialog already has an external_force context with x, y, alpha, r, delta, N, and T.

Key gaps

Point-of-use gap

The external-force row in CellTypesTab.tsx is still a raw text input. It does not open the rich formula editor.

Preview mismatch

The current graph preview expects a finite number over time. Vector formulas such as 5 * N need a vector-aware preview and validation scope.

Variable mismatch

Runtime cell formulas can use variables like age, alpha, r, and delta, but the cell-type editor panel only lists the base time/value variables.

Documentation seed

The help popover has good external-force text, but the user-facing docs index only links model and statistics pages. Rich formula design docs live under docs/superpowers, not the app docs.

Variable table pattern

Variable Plain-language meaning Precise definition to show on expand Example
x, y Cell nucleus position relative to the geometry center. x = X.x - C.x, y = X.y - C.y abs(x) < 10
alpha, r Polar position around the tissue. Bottom is zero angle. alpha = atan2(x, -y), r = sqrt(x^2 + y^2) 10 * sin(alpha)
N Unit normal from the basal curve into the tissue at the closest basal point. N = basalGeometry.getNormal(a), where a = projectPoint(X) 3 * N
T Unit tangent perpendicular to the basal normal. T = (-N_y, N_x) 5 * T + 2 * N
delta Signed distance from the basal curve along the normal direction. delta = dot(N, X - a) delta * N

Terminology to settle

The old external-force design notes describe N as polar/outward in places. The current implementation uses basalGeometry.getNormal(projectPoint(X)), described in code as pointing into tissue, then T=(-N_y,N_x). The docs should teach the implementation, and the old spec can remain historical.

Recommendation: use "basal normal into tissue" and "tangent perpendicular to basal normal" everywhere in user-facing copy.
